# 영문판 (트랜스크리에이션)

## 원칙
- **직역하지 않는다.** 논지와 목소리를 살려 영어로 다시 쓴다. 한국 독자에게만 통하는 맥락(고유 인명·제도)은 한 줄로 풀어준다.
- 독자: 해외 출판사 편집자, 번역가, 페스티벌 프로그래머, 한국학 연구자. 이들에게 실제로 유용하고 새로운 관점을 준다.
- 판소리·고전 용어는 로마자 + 짧은 설명(예: *pansori*, Korea's sung-storytelling tradition) 병기하되, 설명이 글의 리듬을 끊지 않게.
- 톤은 국문판과 같은 사람의 목소리. 과하게 격식적이거나 논문투로 흐르지 않게.

## 산출
- 원문 링크드인/블로그와 짝을 이루는 영어판을 별도 파일로.
- 링크드인 영문판은 영어권 커뮤니티 관례(짧은 훅, 줄바꿈)를 따르되 해시태그는 절제.
