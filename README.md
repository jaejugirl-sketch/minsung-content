# 콘텐츠 엔진 (Orca × Claude Code)

경력을 끌어올리는 사고 리더십 콘텐츠(링크드인·블로그·책)를 생산하고 축적하는 저장소.
Orca ADE에서 Claude Code 에이전트를 병렬로 돌려 운영한다.

## 지도
- `CLAUDE.md` — 상시 맥락 + 목소리 절대 규칙(꼭 먼저 읽기)
- `.claude/skills/` — 콘텐츠-보이스(토대), 링크드인, 블로그, 영문판, 콘텐츠-파이프라인
- `.claude/agents/` — 동향수집관 / 앵글기획관 / 초안작성관 / 보이스검수관
- `시드/seeds.md` — 글감 수집함
- `초안/` `발행/` — 작업/완성 글
- `책/책맵.md` — 챕터 축적

## 흐름
시드 → 앵글기획(사람이 각도 선택) → 초안(팬아웃 레이스) → 보이스검수 → **사람 최종 게이트** → 발행·축적
자세한 규격은 `.claude/skills/콘텐츠-파이프라인/SKILL.md`.

## 첫 실행
`실행가이드.md` 참고.
