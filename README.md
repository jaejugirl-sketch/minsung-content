# 콘텐츠 엔진 (Claude Code 루틴)

경력을 끌어올리는 사고 리더십 콘텐츠(링크드인·블로그·책)를 생산하고 축적하는 저장소.
재료 수집은 클라우드 루틴이 매일 자동으로 돌리고, 글쓰기·발행은 사람이 직접 세션을 열어 진행한다.

## 지도
- `CLAUDE.md` — 상시 맥락 + 목소리 절대 규칙(꼭 먼저 읽기)
- `실행가이드.md` — 자동 루틴 설정법 + 수동 글쓰기 절차
- `.claude/skills/` — 콘텐츠-보이스(토대), 링크드인, 블로그, 영문판, 콘텐츠-파이프라인
- `.claude/agents/` — 동향수집관 / 앵글기획관 / 초안작성관 / 보이스검수관
- `시드/seeds.md` — 글감 수집함 (동향수집 루틴이 자동 충전)
- `초안/` `발행/` — 작업/완성 글
- `책/책맵.md` — 챕터 축적

## 흐름
자동: 동향수집 루틴이 매일 시드 충전 → 이메일 발송 → 커밋·push
수동: 시드 → 앵글기획(사람이 각도 선택) → 초안 → 보이스검수 → **사람 최종 게이트** → 발행·축적
자세한 규격은 `.claude/skills/콘텐츠-파이프라인/SKILL.md`, 실행 절차는 `실행가이드.md`.

## 첫 설정
`실행가이드.md`의 A절(자동 루틴 설정) 참고.
